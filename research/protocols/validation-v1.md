# Frozen validation protocol v1

Declared before validation inference. The first discovery ablations have been inspected; this is a fresh, small synthetic validation panel, not a claim of an external benchmark or blinded independent study.

## Question and fixed arms

Evaluate whether Fable's V-only restoration generalizes the observed literal-copy recovery, and quantify losses in output contracts and simple code-return expressions. Compare original Fable, V-only restoration, all-QKV restoration as a broad rollback control, and a uniformly BF16-aligned parent stored in F16. Add original Qwen Q8 and LFM3 QAD as reference subjects, not paired weight interventions.

V-only is not an accepted repair: the discovery explanation proxy regressed. It is a diagnostic candidate whose tradeoff must be reported. Full QKV may erase specialization. No claim of preserved coding specialization follows from these simple expression fixtures.

## Frozen data and execution

- `datasets/validation-v1-frozen.json`: 48 newly authored fixtures (12 literal copies with new payload forms, 12 new JSON-field combinations, 12 dictionary-return code statements, and 12 complete/missing/conflicting evidence decisions).
- Fixed system prompt from the initial discovery baseline. No schema constraint, prompt improvement, or dose/site selection on these outcomes.
- Fable and aligned-parent arms: seeds 17 and 29, max 128 generated tokens, same sampling as discovery. Qwen/LFM3 references: seed 17.
- Eight Fable/control runs and two reference runs: at most 480 requests / 61,440 generated tokens. Stop and log if the predeclared run/global budget is exceeded.
- Source/config/data/artifact hashes committed before inference. Run evidence is immutable.

## Outcomes and limits

Primary: paired literal-copy exact success per prompt, averaging a prompt's two seeds rather than treating them as independent questions. Report raw counts, rescues/losses, and prompt-clustered uncertainty. Secondary: JSON payload and strict contract, dictionary-return static expression proxy, evidence-decision contract, and truncation. Explanation quality is outside this panel.

Report all arms/categories even if the candidate fails. This panel may validate a narrow behavioral change; it cannot establish a useful overall model improvement or prove retention of the original fine-tuning's code advantage. Do not use it to select further patches and later label that same panel held-out.
