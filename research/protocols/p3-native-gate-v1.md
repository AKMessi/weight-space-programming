Twenty-four visible calibration prefixes: six task forms, each with four fixed prefix lengths/continuations. CPU callback and Vulkan callback evaluate the same prefixes. Each retains the last-column `result_norm` from the same forward pass and complete native logits in ignored binary files with hashes. Compare the FP32 output-matrix product: equal top-1, max centered error <=0.001 and relative centered error <=0.001 for CPU; <=0.05 and <=0.01 for Vulkan. Center on native top-1, compare native top-64; norm denominator max(norm(native centered top-64),1e-6). Full manual top-1 must match too. Failing a threshold stays failed.

Two prefixes per backend additionally run without any callback; require full-logit max error <= the respective backend centered-error tolerance and equal top-1, and report exact equality. A result-norm intervention adds a fixed 0.01*sin(index) vector on those two prefixes, checking the immediate saved-state change and predicted centered-logit shift. These are synthetic causal controls, not natural repairs. Teacher-forced prefixes are diagnostic scored tokens, not generated outputs.
