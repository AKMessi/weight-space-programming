# P3 Fable adapter recovery: numerical stage v1

Declared before spectral/quality outcomes. Sources are the previously pinned Fable F16 and aligned BF16-value parent in F16 layout. Analyze all 18 Q/K/V deltas; compare their singular-value spectra with the public F16 parent and same-source deterministically BF16-rounded parent. Record rank-energy curves at ranks 4,8,16,32,64 and numerical residuals. The 9 tiny non-QKV residual tensors are encoded as explicit sparse index/value corrections, never a hidden dense payload. A substantial non-QKV mismatch fails the package stage rather than silently including the whole model.

Primary package family: truncated SVD ranks 4,8,16,32,64, F16 factors, plus rank32 with deterministic BF16 output-value rounding. Comparators: per-row signed int8/int4 delta and an uncalibrated sign/mean-absolute-scale one-bit delta. The latter is not full BitDelta (no distillation/training). Aligned versus unaligned SVD spectra are numerical controls; source provenance and within-source rounding remain distinct. Any additional package is separately declared before quality feedback. SVD is closed-form linear algebra, not a target training loop.

Every package records complete matching base/reference hashes, array layout/scales/metadata, package bytes, per-matrix reconstruction error and source commit. Merge into a new ignored F16 GGUF; verify every touched/untouched tensor and unchanged base hash. No original adapter identity is claimed. Target package size <=5 MB is a hypothesis. Exact 20.3 MB checkpoint patch remains the lossless baseline. Approximation quality and native loader behavior must be measured separately before claiming a usable recovered adapter.

Freeze new repository-disjoint development/calibration/confirmation fixtures and generation settings before any model-quality selection. Up to 12 numerical candidates, shortlist using a fixed small calibration screen, freeze the package before full fresh confirmation. Existing toy/confirmation data is history, not new confirmation. The quality stage will be declared separately when dataset identities/length policy are pinned, within 80,000 generated and 25,000 separately scored tokens. All compact evidence and failures are published; binary packages/traces/models remain ignored with hashes.
